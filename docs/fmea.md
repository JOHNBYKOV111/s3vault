# FMEA: Анализ отказов

| # | Отказ | Влияние | Обнаружение | Реакция | Проверка |
|---|-------|---------|-------------|---------|----------|
| 1 | **Диск с чанком недоступен** | Потеря одной реплики | Ошибка чтения из `dirA`, fallback на `dirB` | `Heal` восстанавливает из `dirB` в `dirA` | `TestHeal` |
| 2 | **Процесс убит (SIGKILL)** | Незавершенный PUT | WAL replay при старте | WAL восстанавливает состояние (объект либо цел, либо отсутствует) | `TestReplayAfterSIGKILL` |
| 3 | **Postgres недоступен** | Нет записи метаданных | Healthcheck `/readyz` → 503 | Сервер переходит в read-only (или 503 на PUT) | (Chaos-тест с отключением Postgres — TODO) |
| 4 | **Redis недоступен** | Нет кеша | Метрика `cache_miss` | Работаем без кеша (деградация, но не отказ) | (Тест с отключением Redis — TODO) |
| 5 | **Диск полон** | PUT не может записать | Метрика `disk_usage` > 90% | 507 Insufficient Storage, read-only | (Тест с заполнением диска — TODO) |
| 6 | **Split-brain (2 инстанса)** | Конфликт метаданных | Lease истек | Fencing (advisory lock), второй инстанс → 503 | `TestLeases` |
